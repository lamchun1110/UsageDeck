UsageDeck

Privacy Policy

Effective August 28, 2026

UsageDeck is an open-source desktop application distributed under the MIT License. This policy explains what information the application and this website handle.

Summary

UsageDeck has no UsageDeck account system or UsageDeck-operated backend. The project does not add analytics, advertising, behavioral tracking, or telemetry to the application or website. Application data is stored on your device. UsageDeck is not an offline-only application: when you refresh a provider, it communicates directly with the third-party service you configured or authenticated.

Information stored on your device

Depending on the features and providers you use, UsageDeck may store locally:

  • application settings and provider display preferences;
  • usage, quota, reset-time, token-history, and estimated-cost data;
  • diagnostic logs designed to redact credentials and sensitive values;
  • API keys you add, stored through your operating system's credential store where supported; and
  • cached pricing and update information.

The UsageDeck project does not receive this locally stored information.

Third-party provider communication

To retrieve usage and quota information, UsageDeck sends requests directly from your device to the providers you select. These requests may include provider authentication material, account identifiers, and technical request information required by that provider. The provider receives and processes those requests under its own privacy policy and terms. UsageDeck does not proxy these requests through a UsageDeck-operated service.

Local sign-in data and API keys

For supported providers, UsageDeck may read authentication data previously stored by the provider's CLI or desktop application. API keys entered in UsageDeck are stored locally and are used only to make the provider requests you initiate or enable. UsageDeck does not send provider credentials to the UsageDeck maintainers.

Updates and downloads

UsageDeck checks GitHub Releases for application updates and may download an update from GitHub when you approve or enable that behavior. GitHub may receive standard connection information such as your IP address and user agent. GitHub handles that information under the GitHub General Privacy Statement. Update packages are cryptographically verified by UsageDeck.

Website

The UsageDeck website does not set project-operated analytics or advertising cookies and does not include project-operated tracking scripts. It is hosted using GitHub Pages, so GitHub may process standard hosting logs and connection information under its own privacy statement. Links to third-party websites are governed by those sites' policies.

Retention and your choices

Local data remains on your device until you reset the relevant settings, remove a saved API key, clear application data, or uninstall the application. Data already received by a third-party provider is subject to that provider's retention rules. You can stop provider communication by disabling or removing the provider or its credentials.

Children

UsageDeck is a developer utility and is not directed to children. The project does not knowingly collect children's personal information through a UsageDeck-operated service.

Changes to this policy

Material changes will be published on this page and committed to the public UsageDeck repository. The effective date above identifies the current version.

Contact

For general privacy questions, open a GitHub issue without including credentials or private account data. If your report contains sensitive security information, use GitHub private vulnerability reporting.

Open source

You can inspect how UsageDeck handles data in the public source repository. UsageDeck preserves its lineage and attribution to OpenQuota and OpenUsage.
